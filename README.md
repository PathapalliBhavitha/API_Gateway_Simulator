# API Gateway Simulator

## Overview
This project simulates an API Gateway system using FastAPI.

It includes mock APIs for:
- evaluation
- decision
- monitoring

The gateway routes requests between modules and supports:
- timeout simulation
- invalid payload handling
- inconsistent mock responses

---

## Features

- Mock microservices
- Request routing
- Integration testing
- Error simulation
- FastAPI backend
